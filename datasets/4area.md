# ReSDDP 4 area model
This notebooks demonstrates optimization of a simple 4 area model with the Open Source model ReSDDP.

## Julia environment
We use _ReSDDP_ which is preinstalled and precompiled on vLab.

```julia
using ReSDDP
datapath = "./4area/";
```

Model parameters are loaded into workspace by executing the ```params.jl``` file.

```julia
include(joinpath(@__DIR__, datapath, "params.jl")); # Import parameters
```

The feasibility spaces (cuts representing the thermal produciton) are loaded from file. These can also be generated by ReSDDP, but the process takes some time and don't have to be repeated every time.

```julia
# feas_spaces = feasibility(model, inflow_model, parameters, datapath)
using FileIO, JLD2
file = FileIO.File(format"JLD2", joinpath(@__DIR__, datapath, "feas_spaces.jld2"))
data = JLD2.load(file) 
feas_spaces = data["feas_spaces"];
```

The model is loaded based on LTM input files. The inflow model includes a statistical model of the inflow series.

```julia
model = ReSDDP.load(datapath, parameters) ;
inflow_model = load_inflow(datapath, model, parameters);
```

We initialize the strategy object which is used to store the resulting strategy (cuts). We also initialize initial states for the model.

```julia
strategy = init_strategy(model, parameters);
init_val = init_system(model, parameters);
```

The ```train!``` function generates a strategy for that is saved into the ```strategy``` object for the given model and parameters.

```julia
train!(strategy, init_val, model, inflow_model, feas_spaces, parameters)
```

For the given model and strategy, we can run a simulation to evaluate the outcome for a set of given scenarios.

```julia
results_agg = simulate_aggregated(model, inflow_model, parameters, strategy, feas_spaces, init_val);
# results_det = simulate_detailed(model, inflow_model, parameters, strategy);
```

We define function to view the time-series results.

```julia
using Plots
import Statistics
gr()
function plot_result(result::Array, areas, scenarios, weeks)
    # Plot results as spaghetti plots
    plot_instance = plot()
    for area in areas
        for scen in scenarios
            plot!(result[area, scen, weeks, :] |> transpose |> vec, label="A $area, S $scen")
        end
    end
    return plot_instance
end
plot_result(results_agg.PriceTable, 1, 1:10, 1:52)

function plot_quantiles(result::Array, area; quantiles=[0, 0.1, 0.5, 0.9, 1.0])
    n_area, n_scen, n_week, NK = size(result)
    # Plot scenarios as percentiles
    n_quantiles = length(quantiles)
    ts = zeros(n_week * NK, n_scen)
    qs = zeros(n_week * NK, n_quantiles)
    # Convert weeks and timesteps to vector
    for scen in 1:n_scen
        ts[:, scen] = result[area, scen, :, :] |> transpose |> vec
    end
    # Find quantiles for each timestep
    for t in 1:(n_week * NK)
        qs[t, :] = Statistics.quantile(sort(ts[t, :]), quantiles)
    end

    # Create plots, plot quantiles and median
    p = plot()
    for i in 1:Int(floor(n_quantiles/2))
        plot!(
            p, qs[:, i],
            fillrange = qs[:, n_quantiles + 1 - i],
            fillalpha = (0.5/n_quantiles)*i,
            linecolor=:blue,
            fillcolor=:blue,
            linewidth=.5
        )
    end
    plot!(
        p, qs[:, Int(ceil(n_quantiles/2))],
        linecolor=:blue,
        linewidth=1
    )
    return p
end
```
